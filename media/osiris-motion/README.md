# Osiris motion clips

Created for Fjord Flow from the owner's approved Osiris cat portrait, using Higgsfield video generation on 19 October 2026. These are edited raster animations, not a rigged 3D model. No third-party cartoon or YouTube footage is included.

Transparent animated WebP plus static PNG fallbacks: walk (83 frames), listen (48 frames), play (30 frames), 480×270. The play clip ends before an out-of-frame jump. Green-screen removal preserves small enclosed green eye details. All decoded frames were checked for canvas-edge transparency; selected problem frames were visually reviewed.

Playback is silent. The existing explicit cat-sound option remains separate. Reduced motion and hidden pages use a static frame. Private generation records and original source video are kept outside this public repository.
