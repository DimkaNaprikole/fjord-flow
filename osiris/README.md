# Проект Osiris

Отдельный веб-интерфейс внутри Fjord Flow: `/osiris/`. Общий существующий сервер, вход и голосовой виджет; новых ключей и обходов регистрации нет. Установка PWA и отдельная публикация в магазинах пока не реализованы.

## Персонажи и движения

`characters.json` — каталог персонажей. Сейчас добавлен только реальный подготовленный Osiris. Для нового зверя добавить уникальный id, имя, вид и состояния; чужого кота не выдавать за Осириса.

Для каждого состояния: animation (прозрачный анимированный WebP), still (прозрачный PNG). Пути относительно корня сайта. Состояния idle, walk, listen, play; будущие run, groom, stretch, greet добавлять после готовых клипов. Новые состояния автоматически в интерфейсе пока не появляются.

## Приёмка нарезок

- Кот целиком в кадре; одинаковый масштаб и линия пола.
- Нет зелени между лапами и у хвоста; проверять все кадры на светлом и тёмном фоне.
- Проверять начало/конец цикла, походку и направление; хранить оригинал отдельно.
- Для каждой нарезки сохранить источник, разрешение/лицензию, таймкоды и дату. YouTube-ссылка служит референсом; права на использование самого ролика нужно установить отдельно.
- Демо-кнопки движений не включают запись; реальный разговор открывается отдельно.

## Запуск

Из корня сайта: `python -m http.server 8790 --bind 127.0.0.1`, затем `/osiris/`.
Существующая авторизация и серверные ограничения действуют. Проверка живого микрофона требует отдельного пользовательского теста.
